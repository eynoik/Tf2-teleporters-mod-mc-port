# TF2 Teleporters — Minecraft 1.21.1

A NeoForge 1.21.1 port of the classic **TF2 Teleporter** mod from Minecraft 1.7.10.

## Features

- RED and BLU TF2 teleporters
- Original model, textures, GUI and sounds
- Spinning propeller animation
- Frequencies **1–99**
- Maximum **two teleporters per frequency per dimension**
- Teleports players and mobs
- Frequency assignments persist after world/server restarts
- RED and BLU teleporters can pair with either color

## Requirements

- Minecraft **1.21.1**
- NeoForge **21.1.x**
- Java **21**

## Installation

1. Install NeoForge for Minecraft 1.21.1.
2. Put the TF2 Teleporters `.jar` into the `mods` folder.
3. Launch the game.

No additional dependencies are required.

## How to use

Place two teleporters in the same dimension and set both to the same frequency using the teleporter GUI.

Available frequencies range from **1 to 99**. Only two teleporters can use the same frequency.

Once a valid pair is connected, the propeller starts spinning. Stand on an active teleporter briefly to teleport to its paired teleporter.
